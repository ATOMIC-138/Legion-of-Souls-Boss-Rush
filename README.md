# 召喚師割草生存（Legion of Souls: Boss Rush）

一款使用 HTML5 Canvas 與原生 JavaScript 製作的 2D 俯視角生存遊戲。玩家扮演召喚師，一邊走位閃避攻擊，一邊招募並合成隨從迎戰 30 波敵人與首領。

- 線上遊玩：https://atomic-138.github.io/Legion-of-Souls-Boss-Rush/

## 操作方式

| 按鍵 | 說明 |
| :--- | :--- |
| `WASD` / 方向鍵 | 移動 |
| `Space` | 短距離無敵閃現 |
| `E` / 滑鼠右鍵 | 集火號角（短時間提升全軍攻速並集中攻擊滑鼠位置） |
| `R` / `Tab` | 切換隨從陣型（自由狩獵 / 鐵壁護衛） |
| `M` | 開啟或關閉音效與音樂 |

## 玩法簡介

- **招募與升星**：升級時三選一招募隨從，湊齊 3 隻同星級自動合成升星。升至 3 星會解鎖專屬技能；同時擁有兩隻 3 星隨從時，有機率刷出 4 星神話融合卡。
- **羈絆效果**：依據場上隨從的種族與職業組合，自動啟用吸血、減傷、增傷、多重射擊等團隊加成。
- **首領與波次**：共 30 波。每 5 波會出現特色小 Boss；第 10、20、30 波會清空場上雜兵，從該階段的 3 位大 Boss 中隨機出現 1 位進行單挑，擊敗後才進入下一波。
- **地圖事件與成長**：場上會隨機出現可佔領的聖壇與黃金哥布林；結算獲得的金幣可在主畫面升級永久屬性與解鎖外觀，存檔儲存在瀏覽器本機。

## 本機執行

本專案使用 ES Modules，請透過本地 HTTP 伺服器開啟（請勿直接雙擊 `index.html`）：

```bash
npx http-server -p 8080
# 或
python -m http.server 8080
```

啟動後於瀏覽器開啟 `http://localhost:8080` 即可遊玩。
