# ⚔️ 召喚師割草生存（Legion of Souls: Boss Rush）

一款純前端（HTML5 Canvas + Vanilla JavaScript + Web Audio API）打造的 **2D 俯視角召喚師割草生存遊戲**。結合「自走棋三合一升星與羈絆」、「即時走位彈幕首領戰」以及「地圖互動聖壇事件」，開啟瀏覽器即可直接遊玩！

> 🌐 **線上遊玩（開啟 GitHub Pages 後）**：https://atomic-138.github.io/Legion-of-Souls-Boss-Rush/

---

## 🎮 操作方式

| 按鍵 | 功能說明 |
| :--- | :--- |
| **`WASD` / 方向鍵** | 控制召喚師移動閃避彈幕與紅圈預警 |
| **`空白鍵 Space`** | **奧術閃現（Dash）**：朝移動方向短距離無敵衝刺，可穿越怪群與旋轉雷射 |
| **`E` / `滑鼠右鍵`** | **狂暴集火號角**：5 秒內全軍攻速 +100%，並集中火力攻擊滑鼠指向區域 |
| **`R` / `Tab`** | **切換隨從陣型**：一鍵切換【⚔️ 自由狩獵陣（傷害 +15%）】與【🛡️ 鐵壁護衛陣（收縮護主 + 40% 減傷躲招）】 |
| **`M`** | 切換背景音樂與音效靜音（亦可點擊畫面右上角音效按鈕） |

## 🌟 核心玩法特色

### 1. 隨從三合一升星、★3 覺醒大招與 ★★★★ 神話超進化
- 升級時透過三選一抽卡招募 8 種不同職業與種族的隨從，湊齊 **3 隻同星隨從**自動融合升星並巨型化！
- 升至 **★★★ 3 星**時解鎖專屬自動施放的**終極覺醒大招**（如冥界死神斬、天火隕石雨、天罰雷暴、萬箭穿心等）。
- 當場上同時擁有 **2 隻 ★★★ 隨從**時，升級抽卡將出現彩虹流光的 **★★★★ 神話融合卡**，可融合降臨傳說級神話泰坦：
  - **毀滅機神・歐米茄**：`★★★ 發條射手` + `★★★ 重裝機兵`
  - **深淵冥王死神・塔納托斯**：`★★★ 骷髏步兵` + `★★★ 虛空潛影`
  - **荒古狂雷戰神・芬里爾**：`★★★ 祭祀巨熊` + `★★★ 荒野狂戰`

### 2. 10 大全局羈絆系統
集齊指定種族或職業標籤（不死族、機械、戰士、射手、牧師、法師、元素、刺客、虛空、野獸）即可觸發強大團隊增益，包含吸血、死亡復活、減傷、反傷、追蹤飛彈、多箭齊發與爆擊強化。

### 3. 30 波首領挑戰與「隨機君王清場單挑」
- **逢 5 波次（Wave 5 / 15 / 25）**：登場擁有專屬衝鋒、狙擊或交叉斬擊機制的特色小 Boss。
- **逢 10 波次（Wave 10 / 20 / 30）**：**全場雜兵瞬間清空**，進入與傳說君王的**一對一單挑決鬥**！擊敗君王後方可推進至下一波。
- 每階君王波次皆由 **3 位獨立君王隨機降臨 1 位**（共 **9 位傳說君王**，每局體驗皆不同）：
  - **Wave 10 君王池**：煉獄熔岩巨像・伊格尼斯 / 永冬冰霜暴君・波瑞亞斯 / 腐化世界古樹・尤格拉希爾
  - **Wave 20 君王池**：深淵織網女皇・阿拉克涅 / 殲滅機械帝皇・奧米茄零式 / 鮮血緋紅真祖・德古拉
  - **Wave 30 終焉池**：虛空死靈大君・瑪爾扎哈 / 滅世混沌古龍・巴哈姆特 / 墮落六翼熾天使・路西法

### 4. 地圖隨機事件與首領秘寶
- **遠古聖壇事件**：戰場定時刷新「⚡ 雷霆超載聖壇」、「🩸 鮮血獻祭祭壇」、「🌟 星辰賜福聖壇」，依畫面邊緣指標前往站圈佔領即可獲得強大增益或免費升星。
- **貪婪黃金哥布林**：限時 14 秒內集火擊殺逃跑的盜寶哥布林，可爆出大量金幣、全圖磁鐵與回復烤雞。
- **傳說遺物裝備欄**：擊敗首領撿取寶箱可選擇永久強化遺物，並顯示於畫面左上角。

### 5. 局外成長、傳說造型與魔導圖鑑
- 戰役結算提供完整的 **DPS 傷害輸出排行榜** 與金幣獎勵（存檔自動保存於瀏覽器 `localStorage`）。
- 在主畫面可強化 **5 種永久天賦**、解鎖附帶光翼特效與屬性加成的 **主角傳說造型**，並於 **📖 魔導圖鑑** 查看所有隨從大招、神話配方、羈絆與 9 大君王討伐紀錄。
- 內建純程式碼合成的 **Web Audio API 動態分層 BGM 與戰鬥音效**（進入大 Boss 戰自動切換史詩變奏曲）。

## 💻 本機執行方式

由於專案使用原生 ES Modules（`<script type="module">`），請透過任意本地 HTTP 伺服器開啟（請勿直接雙擊 `index.html`）：

```bash
# 方式一：使用 Node.js
npx http-server -p 8080

# 方式二：使用 Python 3
python -m http.server 8080
```

接著在瀏覽器開啟 `http://localhost:8080` 即可開始遊玩！
